# EcoRewards Landing

Sitio estático para presentar EcoRewards con una estética futurista. La landing
vive separada de la app Expo para que pueda abrirse o publicarse sin afectar el
flujo móvil.

## Abrir localmente

Abre `landing/index.html` directamente en el navegador.

También puedes servir la carpeta con cualquier servidor estático. Por ejemplo:

```bash
npx serve landing
```

## Despliegue

Publica el contenido de la carpeta `landing/` en un hosting estático como
Netlify, Vercel, GitHub Pages o Supabase Storage.
