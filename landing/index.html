Del residuo a la recompensa

Así funciona EcoRewards.

01

El usuario ingresa su cuenta

La máquina valida el número de cuenta antes de iniciar.

02

La cámara identifica el material

El sistema reconoce botella o lata y activa el flujo de puntos.

03

Supabase registra el evento

La transacción se guarda y el balance se actualiza en vivo.

04

La app muestra recompensas

El usuario revisa historial, puntos y opciones para canjear.

Arquitectura conectada

Construido para demostrar innovación, sostenibilidad y datos.

La experiencia combina una app móvil Expo, autenticación y datos en Supabase, funciones Edge para acreditar puntos y hardware ESP32 para controlar la máquina recicladora.
